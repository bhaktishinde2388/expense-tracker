# Expense Tracker

This is a full-stack Expense Tracker application built with React.js, Node.js, Express, and MongoDB.  
Users can sign up, log in, add transactions, view their income and expenses, and manage financial records.

## 🚀 Features

- 🌟 User Authentication (Sign Up & Login)
- ➕ Add, View, and Delete Transactions
- 📊 See Total Income, Expense & Net Balance
- 🔒 Protected Routes (only logged-in users can see data)
- 💾 Data stored in MongoDB

## 🛠️ Tech Stack

- Frontend: React, React Router, React Hot Toast
- Backend: Node.js, Express
- Database: MongoDB
- Axios for API calls
